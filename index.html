Pick a block on the left, then click the grid. Drag to move, right-click to delete, Esc to cancel.

Programs (async def main()) arrive in Phase 4.

The full coding guide arrives in Phase 5. Quick start:

1. Place a few belts in a row ending in a Sell block.

2. In Classes → Belt, write and save (Ctrl+S):

class Belt:
    def on_place(self):
        self.direction = "east"

    def on_receive(self, item):
        self.push(item, self.direction)

3. In Classes → Sell:

class Sell:
    def on_receive(self, item):
        self.sell(item)

4. In the terminal: spawn("gear", belt_1)

Each block is its own object: turn one belt with belt_3.direction = "north". Belts take items from behind or either side (so lines can turn corners) and push only forward; Splitters take only from behind and can push forward, left or right; Mergers work like belts. A full block makes items wait behind it. If your code raises an error, that block turns red and stops until you save a fixed class. help() lists more.
